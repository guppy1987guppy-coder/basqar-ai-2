# BASQAR AI 2.0 — бастапқы басты бет

## Іске қосу
1. Node.js LTS орнатыңыз.
2. Осы жобаның бумасын ашыңыз.
3. Терминалда:
   ```bash
   npm install
   npm run dev
   ```
4. Терминалда көрсетілген localhost сілтемесін браузерде ашыңыз.

## Vercel-ге жариялау
GitHub-та жаңа бос репозиторий ашып, осы буманың файлдарын жүктеңіз. Vercel-де сол репозиторийді Import жасаңыз. Framework: Vite. Build command: `npm run build`. Output directory: `dist`.

## Қазіргі нұсқаның шектеуі
Бұл — интерфейстің демо-прототипі. Мектеп деректері браузердің localStorage жадында ғана сақталады. Supabase, аккаунттар, рөлдер, файл сақтау және нақты AI талдауы әлі қосылмаған. Құпия немесе жеке деректерді енгізбеңіз.
